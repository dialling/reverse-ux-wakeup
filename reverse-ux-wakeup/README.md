# 《醒醒！分钱了》(Rise & Fine)

> **“你多睡的每一分钟，都在亲手给室友加鸡腿。”**
> 逆向 UX 挑战赛参赛作品 —— 一款用户每天早上恨得牙痒痒、前一天晚上却抢着交押金绑定的 **4 人寝室早起契约应用**。

---

## 1. 产品立意：为什么“讨厌但不得不用”？

传统温和派闹钟之所以失效，是因为**“关闭闹钟 / 点贪睡”的交互太顺滑了**——人在半梦半醒间靠肌肉记忆盲划就能关掉闹钟继续睡，毫无痛感。

《醒醒！分钱了》彻底反转传统 UX 的“顺滑无感”准则，用 **「自愿受虐逆向交互 + 4人寝室熟人绑定 + 押金内部零和流转」** 构建闭环：
- **不需要外部海量流量**：一个 4 人大学寝室（默认内置 **404 寝室**）即可自给自足运转；
- **讨厌即是核心价值**：它的每一道关卡都在精准折磨半梦半醒的大脑皮层，逼迫你彻底睁眼动脑；
- **不得不用的利益飞轮**：不装它或赖床，你的早饭钱就会变成上铺室友碗里的卤鸡腿；而只要你比室友早醒一步，所有的反人类关卡都变成了你合法“收割室友红包”的提款机！

## 2. 404 寝室预设角色与资金守恒引擎

每位室友每晚向寝室契约账本投入 **`¥50.00`**，形成 **`¥200.00`（20000 分）** 封闭总资金池：

| 床位 | 角色 ID | 昵称 | 人设定位 |
| --- | --- | --- | --- |
| 1号床 | `zhang` | **卷王老张** | 早起狂魔，06:58 准时睁眼盯盘，最爱发起突袭查岗薅室友鸡腿钱 |
| 2号床 | `qiang` | **早八阿强** | 默认男主，深夜立最狠的早起毒誓，清晨打最卑微的社死认怂长文 |
| 3号床 | `li` | **回笼觉小李** | 假醒惯犯，嘴上喊醒了身体缩回被窝，常年被晃动算术精准制裁 |
| 4号床 | `wei` | **死睡阿伟** | 十个闹钟叫不醒的深度睡眠户，404 寝室早餐基金首席慈善赞助商 |

### 刚性资金守恒不变量 (`assertMoneyConservation`)
- 账本内部全部以整数**“分”（cents）**运算，杜绝任何浮点数精度漂移。
- 每次状态迁移均强制断言：
  $$\sum_{i \in \{zhang, qiang, li, wei\}} \text{balanceCents}_i + \text{publicPoolCents} \equiv 20000 \text{ (¥200.00)}$$
- **早起头彩规则**：若尚无室友完成起床核验，期间产生的手滑/犹豫/贪睡罚金先滚入 `publicPoolCents`（公共待分奖池）；一旦首位室友通关打卡立即全额独揽！若已有多名清醒室友，罚金按精确整数除法均分（余数按序精确到 1 分发放），扣款严格以个人剩余押金为上限，绝不穿仓变负。

## 3. 五大逆向 UX 机制与 100% 确定性通关指南

本项目内置 **5 项** 令人抓狂但规则透明、100% 确定性可独立通关的逆向交互机制（源码位于 `src/mechanisms/`）：

### 机制一：躲避手指滑块 + 松手万有引力倒退 (`EvasiveGravitySlider`)
- **逆向折磨点**：未解锁时触碰滑块，滑块会沿轨道随机弹跳闪避并弹出嘲讽；解锁后若闭眼猛甩超速会判定“脱轨”扣罚回零，中途或终点前松手会触发 **9.8G 被窝万有引力** 加速倒吸归零。
- **确定性通关路径**：
  1. 先按住上方黄色 **【STEP 1：防梦游安全栓】满 0.8 秒** 直至显示 `LOCKED`；
  2. 按住滑块看着绿色安全速度表盘，在 **1.5–3 秒内匀速推至最右端（≥98%）**；
  3. 在终点稳稳按住驻留 **0.5 秒** 即可通过第一关。

### 机制二：禁粘贴手打社死认怂长文贪睡 (`ShameTyperModal`)
- **逆向折磨点**：想点「再睡 5 分钟」？彻底拦截 `paste` / `drop` / `Ctrl+V` / 输入法剪贴板整句联想（企图粘贴直接换一套更羞耻的文案重打！）；逐字严苛比对（含中文全角标点 `，`、`！`），打错任意一字整段瞬间清空归零；每磨蹭满 **10 秒** 自动向清醒室友滴血划扣 **`¥1.00`**！
- **确定性通关路径**：根据界面实时高亮的“下一个待打字符”提示（含全角标点提醒），一字不差手动输入整句认怂宣言（兼容中文拼音输入法 `compositionstart/end`），即可获批 5 分钟贪睡，或随时点击绿色按钮放弃贪睡返回起床关卡。

### 机制三：室友突袭查岗 + 晃动乱序键盘算术 (`RaidShakingKeypad`)
- **逆向折磨点**：已起床室友可随时对未起/回笼觉室友发起限时突袭（赌注 `¥10.00`）。被查岗者屏幕警报爆闪，数字键盘整体持续做正弦摇摆倾斜，且**每按一次数字或退格键，`0–9` 键位立即随机洗牌重排**！超时或累计答错 4 次直接扣罚 `¥10.00` 分给清醒室友。
- **确定性通关路径**：每次按键后先看清洗牌后的新键位再点下一位数字，点击 `✓ 提交` 连续算对 **2 道** 两位数加减乘算术题即可反杀保本并正式清醒。

### 机制四：30–60 秒「同色小球不交叉连线」清醒大考 (`FlowConnectGame`)
- **逆向折磨点**：在 `5×5` / `6×6` 配电箱网格中连接全部 5–6 对同色电极；一旦新牵引的折线误碰异色线路或异色端点，立即触发 **“触电短路双崩”**——当前线与被撞无辜线路同归于尽双双清空，并扣罚 `¥0.50`！
- **确定性通关路径**：内置 3 套经 DFS 回溯求解器严格验证 100% 可解的关卡，观察边缘绕行路线（支持沿自身路径回退重绘），互不交叉接通所有颜色即可通关（清醒人类实测约 30–50 秒）。

### 机制五：30–60 秒「无碰撞挪车出库」清醒大考 (`ParkingJamGame`)
- **逆向折磨点**：在 `6×6` 寝室楼下早高峰车棚中平移违停电瓶车，将红色目标车【早八驴】从右侧绿色 `EXIT` 口驶出；拖拽或点按微调时一旦撞上相邻车辆或墙壁，触发宿管大爷咆哮警报，**本车赌气退回本次拖动前原位**并扣罚 `¥0.50`！
- **确定性通关路径**：内置 3 套经 BFS 最短路求解器验证的关卡（最优步数分别为 **10 步 / 12 步 / 14 步**），既可直接拖拽车身，也可用底部 `◀/▶/▲/▼` 1格微调键零刮擦驶出出口（清醒人类实测约 30–60 秒）。

## 4. 快速启动指南（单机导播 + 局域网多手机扫码联机）

### 环境要求
- Node.js `>= 20`（推荐 Node `v22`）

### 进入项目目录并安装依赖
> 注意：外层目录名包含空格（`x 黑客松`），命令行请使用双引号包裹路径：

```bash
cd "reverse-ux-wakeup"
npm install
```

### 方式 A：单机剧本导播模式（零后端依赖，开箱即演）
```bash
npm run dev
```
浏览器打开 `http://localhost:5173`：
- 左侧为高拟真手机壳视图，右侧为 **「404 寝室上帝导播切换台」**；
- 支持一键切换 **第 1–5 幕答辩故事剧本**、一键接管任意室友手机视角、手动拉响闹钟或发起突袭查岗。

### 方式 B：局域网多设备真机扫码实时联机模式（推荐路演互动！）
一键同时启动前端服务（默认 `:5173`）与轻量 WebSocket 实时同步服务（默认 `:5174`）：
```bash
npm run dev:lan
```
（也可分终端独立启动：`npm run sync` + `npm run dev`，同步端口可通过环境变量 `SYNC_PORT=5174` 覆盖。）
- 电脑端导播台底部会自动探测本机局域网 IPv4（如 `192.168.x.x`）并生成 **4 张床位专属二维码**；
- 现场评委或队友用手机连接同一 Wi-Fi / 热点扫码（URL 形如 `http://192.168.x.x:5173/?role=qiang&mobile=1&mode=lan&wsPort=5174`），手机将自动隐藏导播台进入对应室友的**沉浸式全屏真机视图**，扣款红包与突袭查岗全寝室毫秒级同步！
