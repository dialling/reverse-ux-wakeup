## 二、Devpost 上传流程（按官方要求）

Devpost 只接受 **YouTube / Vimeo / 优酷** 的链接，本地 mp4 不能直接上传。步骤：

1. 把 `醒醒分钱了-宣传片-1080P.mp4` 上传到 YouTube（推荐，评委最通用）。
2. 可见性设为 **公开（Public）**。Unlisted 虽能播放，但部分赛事规则要求 publicly visible，公开最保险。
3. 复制视频分享链接（形如 `https://youtu.be/xxxxxxx`）。
4. 回到 Devpost → 你的 submission → **Video demo link** 字段粘贴链接 → Save。
5. 若项目页视频与 submission 不一致，可打开 `devpost.com/software/<your-project>/edit`，把同一链接填进 **Video demo link** 并保存。

> 提交截止后 submission 的视频不可再改，但项目页仍可改。建议先在项目页试填一次，确认能正常播放。

## 五、二次修改

所有画面由脚本生成，改文案 / 改时长 / 出竖屏版都可直接改参数重出：

- `build/render.py`：画面与时间轴（`S = dict(...)` 控制每段起点，`LEVELS` 控制关卡文案）
- `build/audio.py`：配乐（BPM、和弦、段落增益）

重出片命令：
```bash
cd build && python3 render.py && python3 audio.py
ffmpeg -i build/video_silent.mp4 -i build/music.wav \
  -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -shortest -movflags +faststart ../醒醒分钱了-宣传片-1080P.mp4
```
