## 二、 核心产品设计：为什么“讨厌但不得不用”？

传统温和派闹钟之所以失效，是因为**“关闭闹钟 / 点贪睡”的交互太顺滑了**——人在半梦半醒间靠肌肉记忆盲划就能关掉闹钟继续睡，毫无痛感。

《醒醒！分钱了》反转“顺滑无感”的设计惯例，用 **「防盲按清晨核验 + 4人熟人寝室绑定 + ¥200 封闭零和分红池」** 构建自驱闭环：
1. **小圈子自给自足运转**：一个 4 人大学寝室（默认 **404 寝室**四人床位）内部即可完成押金托管与早餐鸡腿分红，无需依赖外部公域流量。
2. **阻力即是唤醒生产力**：每一项核验关卡都精准拦截“半梦半醒盲操作”，促使大脑皮层在 60 秒内彻底清醒。
3. **不得不用的利益闭环**：每晚 4 人各投 `¥50.00` 组成 `¥200.00` 契约池。赖床手滑的每一笔扣罚都会实时打给已起床室友；只要比室友早醒一步，严格的关卡就成了合法收割室友早餐红包的提款机。

## 三、 五重防赖床核验机制与 100% 确定性通关攻略

所有核验机制对迷糊盲按极度严苛，但对清醒操作 **100% 确定可解**：

1. **躲避手指滑块 + 松手 9.8G 万有引力倒退 (`EvasiveGravitySlider`)**
   - **惩罚机制**：未扣安全栓直接碰滑块会随机闪避；猛甩超速触发“脱轨”扣罚 `-¥0.50`；中途松手瞬间倒吸归零。
   - **通关方法**：先长按上方黄色 **【STEP 1：防梦游安全栓】满 0.8 秒** 解锁 → 对照绿色安全速度区在 **1.5–3 秒内匀速推到底** → 在终点稳稳按住驻留 **0.5 秒** 即可通过第一关。
2. **禁粘贴手打认怂长文贪睡 (`ShameTyperModal`)**
   - **惩罚机制**：申请再睡 5 分钟时拦截一切复制粘贴（企图粘贴会自动更换更长的宣言重打）；打错任意一字（含中文全角标点 `，`、`！`）整段清空归零；每犹豫满 **10 秒** 自动向清醒室友划扣 **`-¥1.00`**。
   - **通关方法**：对照逐字高亮提示手动输入整段宣言（或点击绿色按钮放弃贪睡直接起床保本）。
3. **室友突袭查岗 + 晃动乱序键盘算术 (`RaidShakingKeypad`)**
   - **惩罚机制**：已醒室友可对赖床/回笼觉室友发起 `¥10.00` 限时查岗。数字键盘持续正弦倾斜摇摆，且**每按一次按键，`0–9` 键位立即重新随机洗牌**；超时或错满 4 次立扣 `¥10.00` 均分给清醒室友。
   - **通关方法**：每次按键后先看清新键位再按下一位，连续算对 **2 道** 两位数算术题即可保住押金并完成清醒打卡。
4. **30–60 秒「同色小球不交叉连线」清醒核验 (`FlowConnectGame`)**
   - **惩罚机制**：在 `5×5` / `6×6` 配电箱网格连接全部 5–6 对同色电极；误碰异色线路立即触发 **“触电短路双崩”**——两条线路同时清空并扣罚 `-¥0.50`。
   - **通关方法**：内置 3 套经 DFS 回溯求解器证明 100% 满覆盖可解的关卡，沿边缘绕行互不交叉接通所有颜色即可打卡。
5. **30–60 秒「早高峰无碰撞挪车出库」清醒核验 (`ParkingJamGame`)**
   - **惩罚机制**：在 `6×6` 车棚平移违停电瓶车，把红色目标车【早八驴】移出右侧绿色 `EXIT` 口；擦碰任意车辆或墙壁立即触发警报，**本车退回拖动前原位**并扣罚 `-¥0.50`。
   - **通关方法**：内置 3 套经 BFS 最短路求解器验证的关卡（最优步数分别为 **10 / 12 / 14 步**），零碰撞移开阻挡车即可驶出出口打卡。

## 四、 开启局域网多手机 Wi‑Fi 扫码实时联机（可选进阶体验）

若希望使用多台真实手机在同一 Wi‑Fi / 热点下扫码绑定床位实时互动（需本机装有 Node.js `>= 20`）：

- **macOS 免依赖一键启动**：直接双击本目录下的 **`一键启动局域网联机服务.command`**（内置预编译零依赖服务端 `lan-standalone-server.cjs`，**无需联网、无需 `npm install`、无需 `node_modules`**，0.3 秒启动局域网多手机扫码同步服务并自动打开浏览器；若目标电脑未装 Node.js 亦会自动打开 4 机同屏版 HTML）。
- **Windows 免依赖一键启动**：直接双击本目录下的 **`一键启动局域网联机服务-Windows.bat`**。
- **跨平台命令行启动**：
  ```bash
  cd "./项目完整源码/reverse-ux-wakeup"
  npm install
  npm run dev:lan
  ```
  浏览器打开 `http://localhost:5173`（或 `http://localhost:5173/?view=quad`），手机扫描总控台底部的 1–4 号床二维码即可全屏绑定床位实时联机。
